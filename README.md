# Zumma — My Holiday

Website wisata tropis responsif.

## File proyek
- `index.html` — struktur halaman
- `style.css` — gaya dan layout responsif
- `script.js` — interaksi dan fitur demo

## Menjalankan di HP
Download semua file ke folder yang sama, lalu buka `index.html` dengan browser atau preview editor HTML. Internet diperlukan untuk memuat foto Unsplash.

## Publikasikan dengan GitHub Pages
1. Buat repository GitHub bernama `zumma-my-holiday`.
2. Upload `index.html`, `style.css`, dan `script.js` ke root repository (README boleh ikut).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu **Save**.
5. Tunggu proses deployment selesai dan buka URL GitHub Pages yang diberikan GitHub.

## Catatan fitur
Profil akun, favorit, itinerary, dan rencana perjalanan adalah demo lokal yang disimpan di browser menggunakan `localStorage`. Cuaca adalah data contoh, bukan prakiraan langsung. Form booking hanya menyimpan rencana dan belum memesan tiket atau menerima pembayaran. Untuk akun online, cuaca live, dan booking sungguhan perlu backend/API.
